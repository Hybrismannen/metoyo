# METOYO

> **When there is room for more.**

**METOYO** is the public-facing brand, condition, and ritual space for a memory-driven system of reflective giving.  
**The Gift Whisperer** is the internal operating engine: the prompt architecture, ritual logic, persona system, and execution intelligence that runs inside METOYO.

**Canonical rule:** *METOYO names the space and condition; The Gift Whisperer runs the place.*

### Foundational principles

- **Memory precedes the object.**
- **Relationship defines the logic.**
- **Gesture completes the meaning.**
- **Invitation, not interruption.**
- **Presence over performance.**
- **No growth-hacking logic, coercive loops, gamification, or relationship profiling.**
- **Forget-by-default.**
- **The system should become less necessary as the user becomes more capable of remembering and giving.**

METOYO is not intended to be a marketplace, wishlist engine, CRM, behavioral advertising surface, or retention machine.

## The Trident

Every completed whisper resolves into three actionable layers:

| Layer | Function | Question |
|---|---|---|
| **Gift** | symbolic object, act, message or experience | *What could carry this memory?* |
| **Source** | how or where it can be found, made or adapted | *How does it enter the world?* |
| **Ritual** | how it should be presented so that the gesture lands | *How should it arrive?* |

The output is not meant to substitute for care. It is scaffolding for care.

---

## Design doctrine

METOYO is built around **room**: enough space for memory, interpretation, restraint, ambiguity, cultural variation and human judgment.

The system therefore avoids:
- urgency mechanics;
- compulsive notifications;
- streaks, scores and reward loops;
- hidden persuasion;
- emotional-data monetization;
- recommendation pressure;
- unnecessary retention of user inputs.

A good interaction should leave behind a gesture, not a dependency.

---

## Provenance rule

Do not retroactively rewrite historical source material merely to make terminology look uniform. Where a 2025 artifact says **The Gift Whisperer**, that records the engine's original development context. Where the public system is described now, use **METOYO** and name The Gift Whisperer as the internal engine.

This distinction is architectural, not cosmetic.

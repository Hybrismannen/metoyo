# METOYO 1.0 Product Definition

## Product statement

METOYO is a quiet digital ritual space that helps a person move from **remembering** to **meaningful gesture**.

It is not primarily a shopping interface. It is not a relationship profiler. It is not a recommendation feed.

The internal engine, **The Gift Whisperer**, converts sparse relational memory into a structured offering while preserving human authorship of the final act.

## Primary job

> Help me notice what I remember about this person, turn that memory into an appropriate gesture, and retain enough agency that the result still feels like mine.

## Core contract

Input:
- relational role/persona;
- 3–5 memory fragments;
- optional tone;
- optional constraints;
- optional spatial context.

Output:
- **Gift** — symbolic object, act, experience, letter or gesture;
- **Source** — how/where it can be obtained, made or accessed;
- **Ritual** — how it arrives or is enacted.

The output is a proposal. The user must be able to alter, regenerate, reject or ignore it.

## Primary path

```
Arrival
→ quiet framing
→ relationship
→ memory fragments
→ optional context
→ Gift Whisperer interpretation
→ Trident
→ user judgment
→ refine / keep / leave
→ optional reflection
```

## Non-goals

METOYO 1.0 will not be designed as:

- marketplace;
- affiliate product feed;
- wishlist manager;
- recipient surveillance tool;
- contact/relationship CRM;
- therapy or diagnostic service;
- emotional scoring system;
- social network;
- engagement-maximizing habit product.

## Success

A successful session may end in:
- an object;
- an experience;
- a message;
- a ritual act;
- a DIY gesture;
- the decision not to give anything;
- a better memory formulation.

Success is not defined by purchase, return frequency or time spent.

## Product invariants

1. Memory comes before catalogue.
2. Relationship context informs tone, not worth.
3. Source never outranks meaning.
4. Ritual is part of the output.
5. User judgment is final.
6. Privacy defaults toward non-retention.
7. The system never requires an account for the core ritual.
8. The recipient is never converted into a behavioral profile.
9. Declining dependence is compatible with success.

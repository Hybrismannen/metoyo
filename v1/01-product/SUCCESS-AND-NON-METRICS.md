# Success Logic and Non-Metrics

## What METOYO is allowed to learn

At product-evaluation level, METOYO may learn whether the ritual is understandable and useful without constructing individual relationship profiles.

Permissible evaluation concepts, subject to HD-002:
- anonymous session completion count;
- failure/error rates;
- aggregate choice of refinement actions;
- accessibility failures;
- opt-in qualitative research;
- voluntary post-use interviews.

## Metrics that must not become the product goal

- session length;
- daily active use;
- streaks;
- return frequency;
- number of saved recipients;
- number of gifts purchased;
- emotional sentiment score;
- “relationship strength” score;
- recipient profile completeness.

## Evaluation questions

1. Could the user move from memory to gesture?
2. Did the Trident feel connected rather than like three unrelated recommendations?
3. Did the user retain authorship?
4. Did the interface demand less personal information than necessary?
5. Could the user leave cleanly?
6. Did any source or ritual introduce unwanted pressure on the recipient?
7. Did the system avoid pretending to know what the user or recipient feels?

## Anti-optimization rule

If a metric improves because METOYO increases dependence, disclosure, urgency or repeated checking, that metric is not evidence of success.

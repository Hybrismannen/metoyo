# User Journey

## Journey J1 — Guest ritual

### 0. Arrival
User sees:
- METOYO name;
- one-line orientation;
- Start / “Make room” action;
- concise privacy cue.

No account wall.

### 1. Relationship
User selects a relational persona.

Until HD-001 resolves disputed constellation placement, the engine consumes persona ID directly and does not require constellation.

### 2. Memory
Prompt asks for 3–5 fragments:
- a phrase;
- a place;
- an object;
- a habit;
- a moment;
- a quality;
- something unfinished.

Fragments can remain terse. The interface must not pressure the user to disclose intimate histories.

### 3. Optional context
Expandable, never mandatory:
- tone;
- budget band;
- time available;
- DIY openness;
- giver location;
- recipient region;
- symbolic origin.

### 4. Interpret
The Gift Whisperer assembles:
- persona logic;
- memory fragments;
- constraints;
- safety policy;
- cultural humility rule;
- Trident schema.

### 5. Trident
One primary proposal appears as a connected whole:
- Gift
- Source
- Ritual

A small rationale can show which memories informed the result without pretending psychological certainty.

### 6. Judgment
User can:
- Keep;
- Refine;
- “Less literal”;
- “More practical”;
- “More playful”;
- “Make it myself”;
- “No object”;
- Start again.

### 7. Exit
Default ending is complete. No forced signup, reminder or social share.

Optional:
- copy/export;
- Save Ritual;
- Reflection later.

## Journey J2 — Saved ritual

Only after explicit opt-in:
- authenticate;
- save selected session artifact;
- show exact stored fields;
- allow delete/export.

Save must not retroactively store discarded raw memory input unless clearly selected.

## Journey J3 — Reflection

Triggered by user, not by compulsory retention loop.

Reflection can ask:
- What did you end up doing?
- What changed from the suggestion?
- What do you want to remember for yourself?

No sentiment scoring and no hidden relationship inference.

## Journey J4 — Unsafe / boundary-sensitive request

System:
1. does not dramatize;
2. avoids facilitating coercion, stalking, trespass or circumvention;
3. narrows the output to low-pressure, consensual forms;
4. preserves the user’s ability to leave.

## Journey J5 — No result

If the engine cannot form a meaningful Trident:
- say the fragments are insufficient or conflicting;
- offer one gentle prompt for another memory;
- allow exit.

Never pad uncertainty with generic shopping suggestions.

# Screen Contracts

## S00 — Landing

**Purpose:** establish room, not explain everything.

Required:
- METOYO wordmark;
- “When there is room for more.”
- concise orientation;
- primary action;
- privacy microcopy.

Forbidden:
- testimonials carousel;
- countdown/urgency;
- product grid;
- login wall;
- behavioral-consent dark patterns.

---

## S01 — Relationship

Headline intent: “Who are you holding in mind?”

Components:
- relational role cards;
- “someone not listed” escape;
- optional explanation that roles guide tone, not classify people.

Selection stores persona ID in session state only.

---

## S02 — Memory

Headline intent: “What comes back?”

Components:
- 3–5 fragment chips/fields;
- examples as form, not prefilled content;
- privacy note;
- continue when meaningful input exists.

Interaction:
- Enter creates next fragment;
- fragments editable/reorderable/removable;
- no autosave server call.

---

## S03 — Context

Collapsed by default.

Fields:
- tone;
- budget band;
- time;
- DIY openness;
- giver place;
- recipient region;
- symbolic origin.

Every field includes “skip”.

---

## S04 — Generating

Visual:
- restrained breathing/ink/line motion;
- one phrase only;
- no fake percent.

Function:
- submit one normalized request;
- cancellation if supported;
- duplicate protection.

---

## S05 — Trident

The three arms render as a single composition.

### Gift
Name/form + short meaning.

### Source
Find / make / ask / local category / access route.

### Ritual
Mode + action + optional words.

Below:
- “Why this connects” memory-link explanation;
- Keep;
- Refine;
- Start again.

Do not render 20 alternatives at once.

---

## S06 — Refine sheet

Preset transformations:
- less literal;
- more practical;
- more playful;
- quieter;
- no object;
- make it myself;
- lower cost;
- easier to source.

Optional short free-text refinement.

---

## S07 — Complete

The ritual is complete without account creation.

Actions:
- copy;
- export;
- save (optional gate);
- reflection (optional);
- close.

No forced sharing.

---

## S08 — Save gate

Before auth:
- exact fields that will be stored;
- exact fields that will not;
- deletion/export statement.

Never store discarded generations by default.

---

## S09 — Reflection

Journal-like, sparse.

Questions:
- What did you end up doing?
- What did you change?
- What do you want to remember?

No star rating. No sentiment score.

---

## S10 — Privacy

Readable product-level explanation:
- what is processed;
- what is transient;
- what optional saving means;
- provider boundary;
- deletion/export;
- analytics state.

It must reflect deployed reality, not poetic aspiration.

---

## S11 — Error

Types:
- connection;
- model unavailable;
- source lookup unavailable;
- validation;
- session expired.

Always:
- preserve local state where safe;
- say what happened;
- allow retry/back/exit;
- never fabricate a result.

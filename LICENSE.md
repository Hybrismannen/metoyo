# License posture

Unless a file contains a more specific notice, METOYO project documentation and original project materials in this repository are intended to be shared under:

**Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International (CC BY-NC-SA 4.0).**

Summary:
- **Attribution** — credit must be preserved.
- **NonCommercial** — material may not be used for commercial purposes under this license.
- **ShareAlike** — adaptations must be distributed under the same license.

Official license terms:
https://creativecommons.org/licenses/by-nc-sa/4.0/

## Important distinctions

This license posture does not automatically grant rights to:
- third-party trademarks;
- fonts;
- photographs;
- icons;
- external research;
- software dependencies;
- model/provider services;
- material incorporated under another license.

Those materials retain their own rights and license conditions.

## Software

If executable software is later added, the project should make an explicit versioned decision about the software license instead of assuming that the documentation license is appropriate for code.

## Historical contributor agreements

Historical METOYO / Gift Whisperer contributor agreements use the same CC BY-NC-SA 4.0 posture and include project-specific expectations concerning attribution, non-commercial use, privacy and collaboration.

Those drafts should receive contemporary legal review before being relied on as signed contractual instruments.

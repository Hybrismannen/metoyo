# 13 — Design Language

## 1. Design premise

METOYO's visual system is not ornamental branding placed on top of the ritual.

The interface itself should create the conditions for:
- pause;
- memory;
- sensory association;
- calm interpretation;
- deliberate action.

The visual language should feel more like a **ritual threshold, independent publication, letter, or well-made paper object** than a commerce interface.

## 2. Canonical qualities

The interface should be:
- quiet;
- spacious;
- text-led;
- tactile in feeling;
- lightly literary;
- mobile-capable;
- emotionally precise;
- non-performative;
- accessible;
- slow enough to create room without becoming inefficient.

## 3. Historical visual references

The source corpus proposed a visual field inspired by:
- recycled parchment;
- misted glass;
- soft shadows;
- warm neutral backgrounds;
- gentle gradients;
- independent zines;
- Scandinavian stationery;
- Japanese stationery;
- quiet editorial interfaces;
- symbolic rather than literal iconography.

Named historical inspiration references included The School of Life, Are.na and MUBI. These are references for mood/interaction qualities, not templates to copy.

## 4. Typography

Historical proposals leaned toward:
- warm serif typography for headings / invocation;
- legible text face for longer reading;
- occasional monospaced treatment for memory fragments or ritual/system notation.

Examples such as Tiempos/Livory appeared in the decks as mood references.

No commercial font is canonically required.

### Typographic behavior

Use:
- generous line height;
- short text blocks;
- deliberate hierarchy;
- restrained emphasis;
- enough whitespace for pause.

Avoid:
- oversized marketing headlines everywhere;
- constant bolding;
- dense dashboard UI;
- excessive all-caps;
- novelty typography that competes with memory.

## 5. Color

Color fields should function as emotional signals, especially around personas.

They should not:
- encode demographic categories;
- imply diagnostic states;
- become competitive badges;
- overwhelm the reading surface.

A persona may carry a distinctive field, but the system should still work in monochrome/high-contrast modes.

## 6. Icons and symbols

Persona icons should be **symbolic, not portraits**.

Historical examples:
- lantern;
- flame;
- feather;
- spiral;
- vessel;
- compass;
- thread;
- scroll.

The Trident may be represented through three branches corresponding to:

```text
Gift — Source — Ritual
```

Symbols are memory aids, not occult claims or authoritative classifications.

## 7. Motion

Motion should only exist when it contributes to pacing.

Appropriate:
- slow fade;
- gentle reveal;
- transition that resembles turning a page;
- subtle formation of the Trident.

Avoid:
- confetti;
- reward animations;
- pulsing CTAs;
- attention-grabbing loops;
- motion that pressures the user forward.

Respect reduced-motion preferences.

## 8. Core screen rhythm

A canonical interaction can be visually staged as:

### 1. Threshold
One quiet line / invocation.

### 2. Memory
A small input surface for fragments.

### 3. Relation
Persona field.

### 4. Optional place
Spatial meaning, not address capture.

### 5. Whisper
Prompt / short pause / generation state.

### 6. Trident
Three clearly distinguished outputs.

### 7. Exit or reflect
No retention pressure.

## 9. Trident presentation

The Trident should be easy to parse.

Potential layout:

```text
┌─────────────────────┐
│ GIFT                │
│ symbolic possibility│
└─────────────────────┘

┌─────────────────────┐
│ SOURCE              │
│ route into the world│
└─────────────────────┘

┌─────────────────────┐
│ RITUAL              │
│ how it might arrive │
└─────────────────────┘
```

Do not let Source visually dominate Gift and Ritual merely because links are clickable.

## 10. Copy tone

The interaction voice should be:
- calm;
- inviting;
- specific;
- modest;
- sometimes poetic;
- never saccharine;
- never therapeutically authoritative.

Good:
> "Give a few words. Not to explain. To evoke."

Bad:
> "Unlock the perfect gift now."

Good:
> "You may want to give this quietly."

Bad:
> "This is exactly how they need to receive it."

## 11. Commerce boundary

If sourcing links exist:
- they should appear after meaning has been established;
- they should not look like a product grid;
- price should not become the primary sorting logic unless the user asks;
- sponsored placement should not shape ritual output;
- affiliate incentives should not be hidden.

## 12. Accessibility

Poetic restraint cannot become obscurity.

Required:
- sufficient contrast;
- semantic structure;
- keyboard navigation;
- screen-reader labels;
- alternatives to icons;
- readable font sizes;
- reduced-motion support;
- no information conveyed only by color;
- plain-language clarification where a ritual phrase might be ambiguous.

## 13. Design test

Before approving a design, ask:

- Does this feel like a place to remember or a place to convert?
- Is attention directed toward the relationship or toward the interface?
- Can the user stop at any point without friction?
- Does the design preserve room?
- Does the system visually recede after the Trident?

## 14. Canonical design sentence

> METOYO should look composed enough to invite care and quiet enough to get out of the way.

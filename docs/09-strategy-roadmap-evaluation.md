# 09 — Strategy, Roadmap & Evaluation

## 1. Strategic position

METOYO should be developed as a **cultural and relational system**, not as a conventional engagement-maximizing consumer product.

Historical project language framed The Gift Whisperer as:
- a cultural artifact;
- a shared ritual infrastructure;
- a soft system;
- a memory-to-gesture interface;
- a system designed to be used less as the user's own capacity grows.

That strategic inversion remains central.

## 2. Problem field

The source materials describe a cultural drift in which gifting becomes:
- obligation-driven;
- platform-guided;
- rushed;
- generic;
- emotionally outsourced;
- detached from remembered detail.

METOYO's response is not "better recommendations."

It changes the unit of work:

```text
product preference
      ↓ replaced by
relational memory
      ↓
symbolic interpretation
      ↓
gesture
```

## 3. Category claim

Historical documents proposed the category:

> **Memory-Driven Gifting Interfaces**

This remains useful as a descriptive frame, but should not be treated as a verified market category without external research.

## 4. Development logic

Historical strategy used the **InnOVA** arc:

1. **Initiate** — define emotional premise.
2. **Navigate** — map context and differentiation.
3. **Nurture** — compose personas, prompts, visual/ritual system.
4. **Optimize** — refine for resonance rather than conversion.
5. **Verify** — test whether the ritual function works.
6. **Activate** — distribute through narrative, artifacts and collaborations.

The conceptual value of this sequence can be retained even if the implementation roadmap changes.

## 5. Historical MVP path

The 2025 materials proposed:

### Phase 1 — Foundation
- finalize Trident grammar;
- complete masterplan/decks;
- contributor agreements;
- Figma prototype;
- content/database setup;
- funding applications.

### Phase 2 — Soft system build
- lightweight frontend;
- launch persona subset;
- Trident output logic;
- small-group tone testing;
- optional reflection form.

### Phase 3 — Public ritual launch
- narrative publication;
- small open beta;
- anonymized voluntary stories;
- localization;
- optional Ritual Wall;
- stewardship/reporting.

These dates were attached to 2025 planning and should not be read as current schedule commitments.

## 6. Evaluation philosophy

METOYO should not equate success with:
- monthly active users;
- retention;
- session frequency;
- time-on-site;
- conversion to purchases;
- share rate.

Useful evaluation asks whether the system helped produce:
- memory activation;
- greater clarity;
- a gesture that felt proportionate;
- increased confidence in giving;
- more attention to the relationship;
- less future dependence on the tool.

## 7. Historical KPI concepts

The strategic deck proposed indicators including:
- full Trident completion;
- optional reflection uptake;
- spatial-input use;
- return within several months;
- "disappearance" or reduced need.

Historic example targets included:
- 60–70% completion of full Trident flow;
- ≥30% optional reflection uptake;
- ≤40% return within 2–3 months, with declining return interpreted as potentially positive;
- ≥50% spatial input in one planning version.

These targets are **historical hypotheses**, not validated benchmarks.

## 8. Better evaluation layers

A current evaluation framework should separate:

### A. Functional integrity
- Was a complete Trident produced?
- Was the output understandable?
- Could the user act on it?

### B. Relational fit
- Did the user recognize the memory in the suggestion?
- Did the result feel proportionate to the relationship?
- Did they need to heavily correct invented assumptions?

### C. Agency
- Did the user feel free to adapt/reject the output?
- Did the system increase confidence rather than dependency?

### D. Ethical integrity
- Was private data minimized?
- Did any suggestion cross a boundary?
- Did the interaction avoid emotional coercion?

### E. Post-gesture learning
If the user voluntarily reflects:
- What changed in how they thought about giving?
- What did they learn about their own attention?
- Would they approach a future gesture differently?

## 9. Research discipline

Any future claim that METOYO:
- improves relationships;
- increases emotional fluency;
- reduces gift anxiety;
- produces better gifts;
- has particular gender effects;

requires an explicit evidence design.

The source corpus contains hypotheses, theory references, and narrative claims, but these should not be promoted into established causal effects without research.

## 10. Narrative-led distribution

Historical plans emphasized:
- long-form essays;
- small cultural networks;
- design/UX communities;
- zines and printable artifacts;
- card-deck variants;
- museums/libraries/cultural labs;
- relational-tech discussions;
- small betas.

This remains more aligned with the project's ethos than high-pressure growth marketing.

## 11. Artifact ecosystem

Potential forms already present in project planning:
- web ritual;
- prompt webpack;
- PDF mini-zine;
- printable cards;
- physical card deck;
- gift-tag inserts;
- reflection journal;
- cultural installation;
- educator/coach variants;
- localized ritual decks.

Each new artifact must preserve the same core system rather than fragmenting the ontology.

## 12. Strategic release criteria

Do not release merely because the software works.

A METOYO release should be:
- technically stable;
- ethically reviewed;
- tonally coherent;
- provenance-traceable;
- accessible;
- culturally cautious;
- clear about privacy;
- explicit about what is and is not stored.

## 13. North-star formulation

The useful strategic question is not:

> How do we make people return?

It is:

> Did the system create enough room for a person to remember, act, and eventually need less help from the system?
